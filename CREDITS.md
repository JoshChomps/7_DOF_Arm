# Credits & Inspirations

This arm is an original design. The projects below inspired its architecture, sizing, and ideas.
No CAD files or code from them are copied unless explicitly noted (with their license) next to the file.

| Project | Author | License | What it took from them |
|---|---|---|---|
| [PAROL6](https://github.com/PCrnjak/PAROL6-Desktop-robot-arm) | Petar Crnjak / Source Robotics | GPLv3 | Size/payload class, desktop industrial layout, Python API + web commander ideas |
| [Faze4](https://github.com/PCrnjak/Faze4-Robotic-arm) | Petar Crnjak | see repo | Printed cycloidal reducers + belt pre-stages, split of cycloidal (big joints) vs planetary (wrist) |
| [PCrnjak repos](https://github.com/PCrnjak) (Spectral BLDC, SSG-48, differential wrist, s_visual_kinematics) | Petar Crnjak / Source Robotics | various | FOC driver, force-controlled gripper, wrist and kinematics references |
| [Thor](https://github.com/AngelLM/Thor) | Ángel L.M. | CC BY-SA 4.0 | Fully printed student-project arm |
| [Amazing Hand](https://github.com/pollen-robotics/AmazingHand) | Pollen Robotics | Apache-2.0 (code), CC BY 4.0 (mech) | Planned humanoid hand base |
| [OpenArm](https://github.com/enactic/openarm) | Enactic | see repo | 7-DOF SRS research arm reference |
| SpiRobs (logarithmic-spiral robots) | Wang et al. | research | Octopus-inspired tentacle gripper concept |
| [SimpleFOC](https://docs.simplefoc.com) | SimpleFOC community | MIT | FOC learning testbed |
| [ros2-udq-arm-handwriting](https://github.com/ferdy-alpadry/ros2-udq-arm-handwriting) | ferdy-alpadry | Apache-2.0 | Quantized stepper-plant simulation idea (`SimBackend` resolution) |
| [Viser](https://viser.studio) | Nerfstudio team | Apache-2.0 | Digital-twin UI |

Originality check of the full CAD (20 Oct): [docs/20_cad_full_arm.md](docs/20_cad_full_arm.md) §7. Every part is generated by this repo's own scripts; no CAD, URDF or code from the projects above is in it.
